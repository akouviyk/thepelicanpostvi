# Image Assets for The Pelican Post Website

Please add the following images to this directory for the website to display properly:

## Required Images

### 1. Logo
**Filename**: `logo.png` (place in `/public/`)
- **Location**: Root of public directory
- **Recommended size**: 200x200px minimum
- **Format**: PNG with transparent background
- **Description**: The Pelican Post logo (the one with the pelican, text, and icons)

### 2. Location Exterior
**Filename**: `location-exterior.jpg`
- **Location**: `/public/images/`
- **Recommended size**: 1200x1200px
- **Format**: JPG
- **Description**: Photo of The Pelican Post storefront at the Enighed Complex
- **Used on**: Homepage (Why Pelican Post section)

### 3. Owners Photo
**Filename**: `owners-photo.jpg`
- **Location**: `/public/images/`
- **Recommended size**: 800x800px
- **Format**: JPG
- **Description**: Photo of Chris and Francie Kappelmann
- **Used on**: About Us page

## Image Optimization Tips

1. **Compress images** before uploading (use TinyPNG or similar)
2. **Use appropriate formats**:
   - JPG for photos
   - PNG for logos/graphics with transparency
   - WebP for better compression (if supported)
3. **Resize images** to max 1920px width for web use
4. **Maintain aspect ratio** to prevent distortion

## Fallback Behavior

If images are not found, the website will:
- Display emoji placeholders (📦, 👥, etc.)
- Continue functioning normally
- Show gradient backgrounds where images would be

## Adding Images

1. Save your images with the exact filenames listed above
2. Place them in the correct directories
3. Refresh your browser to see the images
